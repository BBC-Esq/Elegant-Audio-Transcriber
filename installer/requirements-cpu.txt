# Note: NeMo is installed normally first, then version overrides applied with --no-deps

# Versions are pinned to the set this app is developed and tested against, so a

# unbuildable sdist, and transformers raising its tokenizers floor.
#
# setup-app.ps1 then applies these on top with --no-deps. Keep the two in sync:
#   transformers==5.5.4  huggingface-hub==1.11.0  fsspec==2024.12.0
#   protobuf==6.33.6     datasets==4.8.4
